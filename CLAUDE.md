# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio for Mehdi Aichouch: a single-page Create React App site (React 18, Tailwind CSS 3) with no router and no backend.

## Commands

```bash
npm start                                          # dev server on http://localhost:3000
CI=false npm run build                             # production build to build/ (CI=false stops lint warnings from failing the build)
CI=true npx react-scripts test --watchAll=false    # run all tests once
CI=true npx react-scripts test --watchAll=false -t "Language switcher"   # run one describe/test by name
```

Linting is CRA's built-in ESLint (`react-app` config), which runs during `start` and `build`. There is no separate lint script.

To build, serve, and visually verify the site at different viewport sizes, use the project skill `.claude/skills/verify/SKILL.md`.

## Environment

Copy `.env.example` to `.env`. Every variable needs the `REACT_APP_` prefix and is inlined into the client bundle at build time:
- `REACT_APP_EMAILJS_*`: used by the contact form (`src/services/contactService.js`, sent through EmailJS).
- `REACT_APP_OPENROUTER_API_KEY`: used by the AI chat assistant (`src/services/chatService.js`).

## Architecture

- **Page layout:** `src/App.jsx` stacks the sections (`Home`, `About`, `Portfolio`, `Skills`, `Experience`, `Contact`) inside `LazyMotion`, `MotionConfig`, `LanguageProvider` and `ResumeModalProvider`. Only the hero renders in the first pass; everything below the fold mounts right after inside `startTransition` (keeps Total Blocking Time down), and a `#hash` deep link is re-applied once it has. Each section is a `<section id=…>`; navigation is plain `<a href="#id">` anchors, with CSS `scroll-behavior: smooth` and `scroll-padding-top: var(--nav-h)` doing the smoothing and header offset. The order and the `01`…`05` micro-label numbers come from `src/data/navLinks.js`, labels from `nav.*` translations. The desktop nav shows from `lg` (1024px) up because the French labels don't fit at `md`.
- **i18n (EN/FR):** `src/context/LanguageContext.jsx` provides `t("dotted.key")`, which looks up `src/i18n/translations.js` and returns the key itself when nothing matches. The chosen language is saved in `localStorage["lang"]`. `t()` can also return arrays or objects. For example, `Experience.jsx` renders `t("experience")` (jobs with `org`, `role`, `date`, `points`), `t("education")` (degrees with `org`, `degree`, `note`) and `t("certification")`. Diplomas deliberately have no dates; only jobs do. Any user-facing text change has to be made in both the `en` and `fr` trees.
- **Projects:** `src/data/projects.js` holds the metadata: image import, link, `hosted`, `category` (`commercial` | `opensource` | `personal`), `tech`, and `descriptionKey`. The description text is at `portfolio.projects.<descriptionKey>` in both languages. `commercial` projects are shown twice: as the "live stores" links in the hero and as the bento cards at the top of `Portfolio.jsx`. Everything else goes in the card grid below, with Magento projects sorted first. Every card opens `work/ProjectDetail.jsx`, a dialog whose image and title share a `layoutId` with the card (shared-element transition). Project images go in `src/assets/projects/`.
- **Resume PDFs are the source of truth for content.** Experience bullets, client-store contributions and `SKILL_GROUPS` in `Skills.jsx` mirror the PDFs in `public/` (spoken languages come from `t("skills.spoken")`; brand icons for skills live in `components/skills/skillIcons.js`, an idle-loaded chunk, and `HAS_ICON` in `Skills.jsx` must list the same names so space is reserved). When the resumes change, update the site and `SYSTEM_PROMPT` to match. Contact and social URLs live in `src/data/contactLinks.js`.
- **Design system:** dark "futuristic, premium, calm" theme. All colors are semantic CSS variables in `src/index.css` (`--bg`, `--surface`, `--surface-2`, `--text`, `--muted`, `--border`, `--border-strong`, `--accent` #4CC9FF, `--accent-soft`, `--live`, `--danger`) mapped to Tailwind names in `tailwind.config.js` (`canvas`, `surface`, `fg`, `muted`, `line`, `accent`, `live`, `danger`), so a light theme only needs to redefine the variables. The cyan accent is used sparingly (the word "anything" in the hero, CTAs, focus rings, active states); green (`live`) is only for the live-store dot. Radii, shadows, the easing curve and the three durations (150/400/800 ms) are tokens too, mirrored for JS in `src/lib/motion.js`. Fonts: Geist 400/600 and Geist Mono 400, self-hosted in `public/fonts/` (subset to Latin + punctuation, preloaded, `@font-face` in `public/index.html`). The font-weight scale is replaced, so only `font-normal`/`font-semibold` exist. Shared classes (`.page`, `.section`, `.eyebrow`, `.section-title`, `.btn-primary`, `.btn-secondary`, `.text-link`, `.chip`, `.card`, `.spotlight`, `.grid-bg`) are in `src/index.css`. There is no logo mark, only the text wordmark.
- **Motion:** `motion` (`motion/react`) with `LazyMotion strict`, so components must use `m.*`, never `motion.*`; features (`domMax`) are passed synchronously (loading them async re-rendered the whole tree in one long task when they arrived). Primitives in `src/components/motion/`: `Reveal` (fade-up once), `SplitHeading` (word-masked title reveal), `ScrollText` (scroll-linked word opacity), `Magnetic` (CTAs); `usePointerCard` gives cards the cursor spotlight and tilt without re-rendering. Animate only `transform`/`opacity`. `MotionConfig reducedMotion="user"` plus the CSS reduced-motion block handle `prefers-reduced-motion`. Premium layer on top: `lib/smoothScroll.js` starts Lenis inertial scrolling on fine-pointer devices only, as a lazy chunk once the page is idle, and skips it with reduced motion. It honours `scroll-padding-top` for anchors, so give it no extra offset. It pauses while `body.overflow-hidden` (modals) is set and leaves `[role=dialog]`/`[data-lenis-prevent]` boxes to scroll natively. Use `scrollToTarget()` for programmatic scrolls. The nav hides on scroll-down (`useHideOnScroll`, translate only) and stays visible for keyboard focus. `RollText` is the hover text roll on CTAs (needs `group` on the button). `.hero-in` (CSS, `--d` delay) sequences the hero after the headline; the subline is left out because it can be the LCP element. Project images get a curtain + settle reveal and client cards a scroll parallax (`MediaImage` in `ProjectCard.jsx`), and `work/CursorPill.jsx` is the "Case study →" pill that replaces the cursor over cards (fine pointer only). Experience dots light up as the progress line reaches them. The footer has the giant gradient wordmark (`.footer-mark`) and the live Fès local time.
- **Hero visual ("the stack"):** `components/hero/HeroVisual.jsx` is pure CSS 3D plus inline SVG, with no WebGL and no extra chunk, so it paints with the first frame everywhere. It shows four glass layers (data, api, commerce, interface; labels at `home.stack.*` in both languages) with a cyan request dot travelling down through them, lighting each layer as it passes. Styles are the `.hs-*` rules in `src/index.css`. Every size is in `cqw` (`.hs-root` is a size container), and the spacing is one registered `@property --gap`, so the intro, the hover "open" state, the beam and the packet all follow it. Desktop only: pointer tilt (`--px`/`--py`, written once per frame) and an `is-open` class from a manual hit-test, because the copy column covers the visual and `:hover` never fires. Labels must be direct children of `.hs-layer` (a `preserve-3d` element) to counter-rotate toward the viewer; inside the flat `.hs-plate` they get flattened. They are hidden below `xl` (1280px), where they would run past the viewport edge. The request loop is the only autoplaying/looping animation on the page; keep it that way (the one-shot hero headline rise and the stack's assembly are CSS).
- **SEO:** `public/index.html` holds the title, description, canonical URL, Open Graph/Twitter tags and a JSON-LD `Person` block; `public/og-image.png` (1200×630, a screenshot of the hero) is the link-preview image, and `public/sitemap.xml` is referenced from `robots.txt`. Regenerate the image if the hero changes noticeably.
- **Logic in hooks and services:** components use hooks (`useContactForm`, `useChat`, `useScrolled`), and hooks call services for network I/O. The contact form sets `noValidate` and runs its own bilingual validation.
- **AI chat assistant:** `chatService.streamChatResponse` is an async generator that streams SSE from the OpenRouter chat-completions API, tries each free model in `MODELS` in order, moving to the next one on an HTTP error or an empty reply (`openrouter/free` is OpenRouter's router across whatever free models are up). Free models are often rate-limited upstream (429) and get retired without notice, so when the chat breaks, first check that the IDs in `MODELS` still exist. Fallback attempts are logged with `console.warn("[AI chat] ...")`. The assistant's knowledge of Mehdi comes entirely from the hardcoded `SYSTEM_PROMPT` in that file. **When projects, the timeline, or skills change, update `SYSTEM_PROMPT` too**, or the chatbot will give outdated answers. A rate-limit error comes back as the sentinel message `"rate_limit"`, which `useChat` detects.
- The chat panel (`components/chat/ChatPanel.jsx`, with the markdown renderer) and EmailJS are lazy-loaded; keep heavy, below-the-fold or on-demand code out of the main bundle.

## Testing notes

Tests are in `src/App.test.jsx` (Jest + Testing Library, rendering the full `<App />`). Test setup already handles these cases:
- `react-markdown` and `remark-gfm` are ESM-only, so the `jest.moduleNameMapper` in `package.json` points them to mocks in `src/__mocks__/`.
- `src/setupTests.js` mocks `matchMedia`, `IntersectionObserver` and `scrollIntoView`, and sets `MotionGlobalConfig.skipAnimations` (jsdom has no layout, so exit/layout animations would never settle). `jest.moduleNameMapper` maps `motion/react` to its CJS build (Jest 27 ignores package `exports`). It also clears `localStorage` after each test so the saved language doesn't carry over into the next test.
